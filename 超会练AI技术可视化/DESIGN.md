# DESIGN.md · 超会练 AI 技术可视化（学术风）

## 1. 风格定位

- **预设分支**：学术风（高校答辩 / 竞赛路演），蓝白克制、证据驱动、可信严谨。
- **核心调性**：技术可信 > 视觉炫技；流程图/表格是主角，不做营销海报。

## 2. 画布与母版骨架

- 画布：1280 × 720（16:9）。安全边距：左右 40，上下按页型。
- 母版三区（内容页锁定）：
  - **A 页眉**：A3 模式——顶部深蓝实色顶条（高 56px）+ 左侧页标题 + 右侧项目名。
  - **B 内容区**：y 80–660（可用 580px 高 × 1200px 宽）。
  - **C 页脚条**：y 660–700——左侧「超会练 · 智能运动健康」，右侧页码「NN / 12」。
- 封面、目录、章节扉页、结束页省略 A/D，自由构图。

## 3. 色彩（≤4 种主色 hex，全篇统一）

| 角色 | hex | 用途 |
| :-- | :-- | :-- |
| 主蓝 | `#1E4FA8` | 顶条、编号、强调、表格表头 |
| 藏蓝 | `#0E3F8C` | 章节大数字、深底、重点结论条 |
| 浅蓝 | `#E8EFF8` | 卡片底、表头浅底、节点填充 |
| 中蓝 | `#3D7BD9` | 流程图第二节点、描边 |
| 文本 | `#1A2230` / `#4A5568` / `#8B97A8` | 主 / 副 / 辅助 |
| 线框 | `#D6DCE5` | 卡片描边、表格线 |
| 背景 | `#FFFFFF` / `#F7F9FC` | 主背景 / 浅底 |

- 警示红 `#D9534F`、数据黄 `#FFC107` 仅作关键数字/结论点缀，单页 ≤3%，全篇金色 = 0。
- 禁用：紫粉玫红、橙绿大色块、彩虹渐变、纯黑大底。

## 4. 字体（≤2 套）

- **思源黑体**（主）：标题、正文、表格、编号。
- **思源宋体 / Georgia**（辅）：仅封面英文长标题、结束页金句。
- 字号梯度：主标 34–40 / 卡标题 24–28 / 正文 18–22 / 表格 16–18 / 页码脚注 14。

## 5. 组件与版式规则

- 流程图 / 架构图：**内联 `<svg>`**（viewBox + rect/text/line/path），节点用浅蓝填充 + 主蓝描边，箭头灰色 1.5px。
- 模型选型标注：流程节点下方用**藏蓝虚线**引出，子节点用浅蓝卡片 + 藏蓝标题，主/回退用「主模型 / 回退」标签区分。
- 对比页：`<Table>` 左 60% + 右结论条 40%（非对称）；表头深蓝实底白字，数据行浅蓝斑马纹，关键格浅红/浅黄高亮。
- 卡片：浅底 `#F0F5FC` + `#D6DCE5` 淡描边，圆角 8；深蓝实色卡单页 ≤1。
- 多卡页必须有**双重锚定**：物理连接（箭头/节点串）+ 共享锚点（底部结论条）。

## 7. 硬闸门（逐页自检）

1. 内容页 B 区累计高 ≥ 500px，不空摆留白。
2. 流程图/表格是主角，不得缩成角标（≥50% B 区）。
3. 红+黄 ≤5%，无金色、无渐变底。
4. 正文 ≥18px，卡标题 ≥24px，无溢出断词。
5. 全篇顶条/页码/项目名一致。
6. 表格页必带结论条，数据后有判断。
