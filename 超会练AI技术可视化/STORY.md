# STORY.md · 超会练 AI 技术可视化（路演版）

## ① 用户意图对齐

- **目标受众**：2026 中国国际大学生创新大赛（产业赛道）答辩评委——学界 + 产业界专家混合，看重「技术有效性 + 落地能力」。
- **核心目标**：让评委亲眼看到 AI 不是黑盒——① 两条 AI 链路的完整处理过程可解释；② 每个关键环节有模型选型与降级容错（非单一模型/非调 API 交差）；③ 从而信服「深度学习驱动的动作评估 + 食物识别」是自研核心技术，而非包装。
- **PPT 长度**：12 页（封面 + 目录 + 3 章节 + 结束）。
- **视觉调性**：学术严谨 / 蓝白克制 / 证据驱动 / 技术可信。
- **内容边界**：必讲——双 AI 能力总览、动作纠错全流程、HRNet vs YOLOv8-Pose 模型差异、食物识别全流程、云视觉 vs 本地 CNN 差异、可视化价值收束；不讲——疲劳管理、社区、教练工作台等其余模块（聚焦两条 AI 链路）。

### 关键数据落点（"所以呢"）

- 17 关键点（COCO）→ 人体骨骼可被精确定位，动作评估有可量化的几何依据。
- 抽帧 60 帧 → 覆盖动作全程，避免单帧误判。
- HRNet 高精度 / YOLOv8 快速 → 精度与速度的工程权衡，非单一模型。
- 云视觉「任意食物」/ 本地 CNN「208 类中国菜」→ 泛化能力与离线可用性的互补。
- 中国食物成分表 1750 条 → 识别结果可直接换算营养，打通「训练-营养」闭环。
